---

## 📌 About The Project

This is my **personal portfolio website** – a central hub to display my work, technical skills, and professional experience. It serves as an interactive resume and project showcase for potential employers, collaborators, and the broader developer community.

The website is built with a focus on **clean design**, **fast performance**, and **responsive layout** to ensure a great experience on all devices.

---

## ✨ Features

- **Modern UI/UX** – Clean, professional, and visually appealing design
- **Responsive Layout** – Optimized for desktop, tablet, and mobile devices
- **Project Showcase** – Displays my key projects with descriptions and links
- **Skills Section** – Highlights technical competencies and tools
- **Fast Performance** – Built with Vite for rapid loading and smooth interactions
- **GitHub Integration** – Links to my repositories for easy access to project code

---

## 🛠️ Technologies Used

- **React** – Frontend framework for building the user interface
- **TypeScript** – Type-safe JavaScript for better code quality
- **Vite** – Next-generation build tool for fast development and bundling
- **Tailwind CSS** – Utility-first CSS framework for custom styling
- **Node.js** – Runtime environment for package management

---

## 🤖 About Vibe Coding

**Vibe Coding** is an approach where developers use AI tools (like GitHub Copilot, Cursor, or ChatGPT) to assist in writing, refactoring, and optimizing code. This project was developed through a collaborative process where:

- **AI Assistance** – Helped generate component structures, styling, and configuration files
- **Human Direction** – Guided the design decisions, project structure, and feature prioritization
- **Rapid Iteration** – Enabled quick prototyping and refinement of the user interface

This approach allows for faster development cycles while maintaining code quality and best practices.

## 🚀 Getting Started

To run this portfolio website locally:

### Prerequisites
- **Node.js** (v16 or higher)
- **npm** or **yarn** package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/SyedMehdiShah05/Portfolio.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```
   or
   ```bash
   yarn install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
   or
   ```bash
   yarn dev
   ```

5. **Open your browser** and go to `http://localhost:5173` (or the port shown in the terminal)

### Build for Production
```bash
npm run build
```
or
```bash
yarn build
```
